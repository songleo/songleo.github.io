这是一个系列文章，主要分享我最近使用chatgpt过程中的一些小技巧，每次分享3点，希望你能有所收获。

### 1 让 chatgpt 帮你写提示词

不熟悉的任务可以先让 chatgpt 把目标、上下文和限制整理成提示词，再交给 codex 执行。比如做离线部署时，我只先说明目标，让它补全“只读调研、不要修改、输出验证方法”等要求。

### 2 多 agent 同时工作

多个相互独立的任务可以交给不同 agent 并行处理，最后让主 agent 汇总结果。比如评估一个离线部署包时，分别让 agent 检查镜像、依赖和脚本，可以更快得到完整结论。

### 3 用 sub-agent 隔离上下文

大量读取、搜索和日志分析可以交给 sub-agent，只把结论返回主 agent，避免上下文被过程信息占满。比如分析大型项目时，让 sub-agent 扫描代码和文档，主 agent 只根据架构摘要继续制定方案。
